Thank you for your interest in contributing to **J.A.R.V.I.S. Mark 54**! We welcome community feedback, issue reports, and documentation enhancements.

## 🐛 2. Reporting Bugs

If you encounter a bug:
1. Check the [Issues](https://github.com/divyanshuvermaai-png/jarvis-mark-54-for-mac/issues) tab to see if the issue has already been reported.
2. Use our **[Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md)**.
3. Provide complete environment details (macOS version, Mac hardware model, RAM, display setup).
4. Include minimal steps to reproduce the issue.

---

## 💡 3. Suggesting Features & Enhancements

Have an idea for a new capability or automation action?
1. Check existing feature requests to avoid duplicates.
2. Use our **[Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md)**.
3. Describe the problem, your proposed command or voice prompt, and the expected system outcome.

---

## 🛡️ 4. Contribution Rules & Safety

- **No Malicious Automation**: Do not propose scripts or actions that perform unauthorized surveillance, bypass macOS security controls, or destroy user data.
- **No Hardcoded Credentials**: Never submit API keys, tokens, passwords, or personal credentials in issues, pull requests, or sample code.
- **Respect Upstream Licenses**: Any third-party libraries referenced must be compatible with standard open-source licenses (MIT, Apache 2.0, BSD).
